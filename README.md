# asset-manager（統合資産管理システム）

タグ・マスタ定義・カスタムフィールドに対応した、ブラウザ完結型の資産管理システムです。
データはブラウザの IndexedDB（Dexie.js）に自動保存され、サーバーは不要です。

## 起動方法

ビルドは不要です。いずれかの方法で開いてください。

```bash
# 方法1: そのままブラウザで開く
open index.html

# 方法2: ローカルサーバーで配信（推奨）
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## 主な機能

- **ダッシュボード** — 「要対応」（期限超過・直近の予定・停止中の資産）を緊急度順に集約、稼働率などの統計、稼働状況の内訳、最近の資産・履歴
- **資産一覧** — リスト / カード / カレンダーの3ビュー、列のカスタマイズ、列ソート、絞り込み条件の常時表示
- **資産詳細** — 基本情報、画像（`Ctrl+V` 貼り付け対応）、構成パーツ（親子関係）、運用手順、リスク管理、周期計画、履歴
- **マスタ管理** — タグの階層管理（リスト / グラフの2ビュー）、タグ固有のカスタムフィールド定義
- **資産構成** — 資産同士の親子関係をグラフで編集
- **横断検索（コマンドパレット）** — `Ctrl+K` で資産・タグ・操作を1つの入口から呼び出し
- **インポート / エクスポート** — JSON形式（画面へのドラッグ&ドロップでもインポート可能）

### 画像の登録

スクリーンショットを撮って、そのまま `Ctrl+V` で貼り付けられます。

| 貼り付けた場所 | 動作 |
| --- | --- |
| 資産の編集中 | その資産の画像として追加し、画像タブへ移動 |
| 一覧・ダッシュボード | その画像を持つ新規資産の下書きを開く |

ドラッグ&ドロップ、ファイル選択、画像URLの入力にも対応しています。
保存前に長辺1600px・WebP品質85%へ自動圧縮するため、大きなスクリーンショットを
そのまま貼っても IndexedDB を圧迫しません（画像の追加・削除は即時保存されます）。

### キーボードショートカット

アプリ内では `?` キーでいつでも一覧を表示できます。

| キー | 動作 |
| --- | --- |
| `Ctrl (⌘) + K` | 資産・タグ・操作を横断検索（コマンドパレット） |
| `/` | 表示中の一覧を絞り込む |
| `N` | 新規資産を登録 |
| `Ctrl (⌘) + V` | 画像を貼り付けて登録 |
| `Ctrl (⌘) + S` | 編集中の資産を保存 |
| `G` → `D` / `G` → `A` | ダッシュボード / 資産一覧へ移動 |
| `1` / `2` / `3` | リスト / カード / カレンダー表示 |
| `?` | ショートカット一覧 |
| `Esc` | 最前面のモーダル・パレット・モバイルサイドバーを閉じる |
| `Delete` | グラフビューで選択中のノード・接続を削除 |

│   ├── components.css      # 検索/資産カード/リスト/ダッシュボード/カレンダー/トースト

│   ├── navigation.js       # サイドバー描画・ページ遷移
│   ├── search.js           # 絞り込み状態の一元管理・検索・コンテキストバー
│   ├── dashboard.js        # ダッシュボード描画（要対応の集約を含む）

## 設計方針（UI/UX）

認知負荷を下げるために、次の原則で作っています。改修時もこれに沿ってください。

1. **色は意味を持つときだけ使う** — UIの大半をニュートラル（slate系）で構成し、
   彩度の高い色は「状態」と「次に取るべき行動」にだけ割り当てます。
   状態色は一般的な連想に合わせています（緑=正常 / 琥珀=注意 / 赤=停止 / 灰=対象外 / 青=情報）。
2. **画面の役割を混ぜない** — サイドバー=「どこを見るか」、ヘッダー=「何をするか」、
   コンテキストバー=「今どういう状態か」。この3層に別種の操作を混在させません。
3. **記憶させない** — 適用中の絞り込みは必ずチップで表示し、ショートカットは操作の近くに常時併記します。
4. **推測させない** — アイコンのみのボタンは使わず、空状態には理由と次の操作を必ず添えます。
5. **元に戻せる** — 破壊的操作は影響範囲を事前に伝えるか、「元に戻す」を用意します。

## カスタマイズのポイント

- **ステータスの追加・変更** — `js/config.js` の `STATUS_DEFS` に1行追加するだけで、
  資産編集画面のチェックボックス・一覧のバッジ色・ダッシュボードの内訳・
  資産構成グラフのノード色に自動反映されます。
- **配色・余白・角丸などのデザイン** — `css/base.css` の `:root` にあるデザイントークンを変更してください。
  プリミティブ（`--blue-600` など）とセマンティック（`--primary`、`--danger` など）の2層構造です。
- **リストの列** — 画面上の「列」ボタンから変更できます（定義は `js/main.js` の `availableColumns`）。
- **画像の圧縮設定** — `js/image-input.js` の `IMAGE_MAX_DIMENSION` / `IMAGE_QUALITY` で調整できます。

## 依存関係

| ライブラリ | 提供元 | 用途 |
| --- | --- | --- |
| Dexie.js 3.2.4 | 同梱（`vendor/`） | IndexedDBによるデータ永続化 |
| Font Awesome 6.4.0 | CDN | アイコン |
| Google Fonts (Inter / Noto Sans JP) | CDN | フォント |

データの保存・読み込みはオフラインでも動作します（アイコン・フォントのみCDN依存のため、
完全オフラインで使う場合は Font Awesome も同様に `vendor/` へ同梱してください）。
